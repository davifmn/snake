O que mudou desde este repositório:

- Os agentes foram separados em duas famílias: **determinísticos** (BFS, DFS, custo uniforme, gulosa, A\*, A\* + caixeiro viajante, A\* ciente do tempo, A\* seguro e ciclo hamiltoniano) e **não determinísticos** (passeio aleatório, subida de encosta, têmpera simulada, Monte Carlo, MCTS e algoritmo genético).
- O `A_STAR` e o `A_NEW_STAR` daqui continuam lá, como "A\* + caixeiro viajante" e "A\* ciente do tempo".
- O NEAT, que nunca chegou a ser implementado, foi substituído por um algoritmo genético que funciona.
- O raciocínio de cada algoritmo aparece passo a passo antes de a cobra andar, e há mapas de obstáculos.

Este repositório fica arquivado (somente leitura) para preservar o histórico original.
